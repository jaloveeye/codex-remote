# Icon Requirements

## English

The following icon files are recommended for VS Code Marketplace publication.

### Required files

#### 1. `icon.png` (required)
- **Size**: 128x128px minimum, 256x256px recommended
- **Format**: PNG, preferably with a transparent background
- **Usage**: shown in the Marketplace and extension list

#### 2. `banner.png` (optional)
- **Size**: 1280x640px recommended
- **Format**: PNG or JPG
- **Usage**: banner image for README or release materials

### Design guidelines

1. Keep the design simple and recognizable at small sizes
2. Use consistent brand colors
3. Prefer high-resolution source assets
4. Use transparency when appropriate

### Suggested tools

- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [GIMP](https://gimp.org)
- [Adobe Illustrator](https://adobe.com/illustrator)

### Note

If `icon.png` is missing, `vsce package` will warn during packaging.
The package can still be created, but the Marketplace listing will show a default icon.

## 한국어

VS Code Marketplace 게시를 위해 아래 아이콘 파일을 권장합니다.

### 필수 파일

#### 1. `icon.png` (필수)
- **크기**: 최소 128x128px, 권장 256x256px
- **형식**: PNG, 가능하면 투명 배경
- **용도**: Marketplace와 확장 목록에 표시

#### 2. `banner.png` (선택)
- **크기**: 권장 1280x640px
- **형식**: PNG 또는 JPG
- **용도**: README 또는 릴리즈 자료용 배너 이미지

### 디자인 가이드라인

1. 작은 크기에서도 식별 가능하도록 단순하게 만듭니다
2. 일관된 브랜드 색상을 사용합니다
3. 고해상도 원본 에셋을 권장합니다
4. 필요 시 투명 배경을 사용합니다

### 권장 도구

- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [GIMP](https://gimp.org)
- [Adobe Illustrator](https://adobe.com/illustrator)

### 참고

`icon.png`가 없으면 `vsce package` 실행 시 경고가 발생합니다.
패키지는 만들 수 있지만 Marketplace 목록에는 기본 아이콘이 표시됩니다.

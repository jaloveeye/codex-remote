# Codex Remote Extension Publishing

## English

Use this guide when publishing the VS Code extension package.

### Checklist

1. Update `codex-extension/package.json`
2. Run `npm install`
3. Run `npm run compile`
4. Package the extension with your preferred VSIX workflow
5. Verify the display name, description, icon, and Marketplace links
6. Smoke test local mode and relay mode before release

---

## 한국어

VS Code 확장 패키지를 게시할 때 사용하는 가이드입니다.

### 체크리스트

1. `codex-extension/package.json`을 업데이트합니다
2. `npm install`을 실행합니다
3. `npm run compile`을 실행합니다
4. 원하는 VSIX 패키징 방식으로 확장을 묶습니다
5. 표시 이름, 설명, 아이콘, Marketplace 링크를 확인합니다
6. 릴리즈 전 로컬 모드와 릴레이 모드를 스모크 테스트합니다

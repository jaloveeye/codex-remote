# Codex Remote Extension Publishing

Use this guide when publishing the VS Code extension package.

## Checklist

1. Update `codex-extension/package.json`
2. Run `npm install`
3. Run `npm run compile`
4. Package the extension with your preferred VSIX workflow
5. Verify the display name and marketplace description show **Codex Remote**
6. Smoke test local mode and relay mode before release

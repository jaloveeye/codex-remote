Codex Remote 소개

Codex Remote는 VS Code 확장과 연동하여, 모바일 또는 웹 브라우저에서 Codex를 원격으로 제어할 수 있도록 설계된 클라이언트 앱입니다.

주요 기능

  • 로컬/원격(릴레이 서버) 세션 연결
  • 실시간 프롬프트 전송 및 응답 스트리밍
  • 세션 히스토리 조회/복원
  • 명령 승인 리뷰(커맨드 승인)
  • 모델/옵션(에이전트 모드/추론 수준) 동적 로드

누가 사용하나요?

로컬 개발 환경에서 Codex를 운영하면서, 휴대폰/태블릿으로 동일 작업을 이어가고 싶은 사용자에게 적합합니다.

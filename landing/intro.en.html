Codex Remote Introduction

Codex Remote is a client app built to control Codex remotely from a mobile device or web browser by connecting with the VS Code extension.

Key Features

  • Local or relay-session connection
  • Real-time prompt sending and streaming responses
  • Session history lookup and restore
  • Command approval review
  • Dynamic loading of models/options (agent mode / reasoning level)

Who is it for?

It is suitable for users who want to continue working on Codex from a phone or tablet while operating from a local development setup.
